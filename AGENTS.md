## Orientation

Use the [documentation map](docs/README.md) and relevant decisions to recover project intent. Hivex knowledge supports the responsible agent; use the installed interface and consult only the sources needed for the task.

## Development

Follow the [engineering guideline](docs/guidelines/engineering.md). Use stable Rust and Git 2.45 or newer; setup and verification commands are in [development guide](docs/guide.md#development). Work is issue-first in `H1V35/hivex`, with coherent PRs and review under the owner's existing authorization.

The owner reserves the final merge decision for each PR. Agents prepare reviewed, passing PRs and do not merge without the owner's explicit approval for that specific PR.
