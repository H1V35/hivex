# Versioned sources before generated knowledge

Markdown and its accepted history record project intent, language, decisions and constraints. Code, executable contracts and tests explain behavior. Generated summaries, search previews, indexes and model output do not overrule those authorities.

Identify the exact source version considered and read enough of its passage to include applicable conditions, exceptions and replacements. A working copy is a source version even without a Git commit; its presence does not establish approval. Report omitted or unavailable evidence instead of assuming a preview is sufficient.

Status is a declaration, not precedence. Read later amendments and explicit relationships before applying a decision. Historical material remains evidence for its original scope; excluding it from ordinary retrieval does not erase it.
